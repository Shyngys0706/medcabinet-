ҚҰРМЕТТІ ПАЙДАЛАНУШЫ ЖӘНЕ ОҚЫТУШЫ!

Бұл жоба арнайы курстық жұмыс (КРС) талаптарына сай толықтай таза 
веб-технологиялар негізінде жасалған:
1. HTML5 (index.html) — семантикалық, таза белгілеу тілі.
2. CSS3 (style.css) — заманауи минималистік медициналық стиль (ешқандай сыртқы фреймворксіз).
3. JavaScript (app.js) — таза ES6 скрипті, DOM манипуляциясы, оқиғалар (Events).
4. LocalStorage — браузердің тұрақты жергілікті деректер базасы.

------------------------------------------------------------------------------
ҚАЛАЙ АШУ КЕРЕК? (ӨТЕ ОҢАЙ — 1 ҚАДАМ):
------------------------------------------------------------------------------
Сізге ешқандай Node.js, npm, GitHub немесе күрделі кітапханаларды орнатудың
МҮЛДЕМ ҚАЖЕТІ ЖОҚ!

1. Осы папкадағы "index.html" файлын тінтуірмен (мышкамен) екі рет басыңыз (Double click).
2. Ол кез келген браузерде (Google Chrome, Microsoft Edge, Opera, Safari) тікелей ашылады.
3. Барлық функционал (кабинеттерді брондау, қабылдауға жазылу, SMS еске салғыштар,
   суретті өзгерту және өшіру, JSON сақтау) бірден 100% жұмыс істейді!

------------------------------------------------------------------------------
ЖҮЙЕНІҢ НЕГІЗГІ МҮМКІНДІКТЕРІ:
------------------------------------------------------------------------------
- Дәрігерлерге кабинеттерді брондау және уақыт аралығын таңдау.
- Науқастарға дәрігердің қабылдауына онлайн жазылу және ресми талонды басып шығару.
- Автоматты SMS/WhatsApp еске салғыштарын жасау және журналдан қарау.
- Жеке кабинеттер мен рөлдер: Дәрігер, Науқас, Әкімші (Жақсылық Шыңғысхан).
- Профиль суретін (аватарын) компьютерден жүктеп өзгерту немесе толық өшіру.
- Кабинеттердің санитарлық өңдеу, бос, брондалған күйлерін өзгерту.
- Мәліметтер базасын кез келген уақытта JSON файлы ретінде сақтау немесе жаңарту.
- 100% офлайн жұмыс істейді (интернетсіз де ашыла береді).
