# MedCabinet — Медициналық кабинеттерді брондау және дәрігерге жазылу жүйесі

**Жоба авторы:** Жақсылық Шыңғысхан  
**Бағыты:** «Медицинадағы интернет технологиялар», 6B06106 – «ІТ медицина»  
**Университет:** Қ. Жұбанов атындағы Ақтөбе өңірлік университеті, 2026 ж.

Бұл қосымша — кез келген серверде (Render, Railway, Ubuntu VPS, Localhost) ешқандай үшінші жақты платформаларға тәуелділіксіз (100% тәуелсіз) дербес жұмыс істейтін Full-Stack веб-қосымша.

---

## 🛠 Технологиялық стек
* **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide Icons
* **Backend:** Node.js, Express, REST API
* **Деректер қоры:** Серверлік тұрақты файлдық база (`server-data/medcabinet_db.json`)
* **Сборка және сервер:** Vite, TSX, Express

---

## 🚀 Компьютерде (Localhost) іске қосу

1. Репозиторийді жүктеп алыңыз немесе клондаңыз:
   ```bash
   git clone https://github.com/Shyngys0706/medcabinet.git
   cd medcabinet
   ```

2. Тәуелділіктерді орнатыңыз:
   ```bash
   npm install
   ```

3. Жүйені әзірлеуші режимінде қосыңыз:
   ```bash
   npm run dev
   ```
   Браузерде: `http://localhost:3000` ашылады.

4. Жобаны өндіріске жинау (Production build):
   ```bash
   npm run build
   npm start
   ```

---

## 🌐 Кез келген серверде (Render.com / Railway / VPS) іске қосу

* **Build Command:** `npm install && npm run build`
* **Start Command:** `npm start`
* **Port:** `3000` (немесе жүйелік `process.env.PORT`)
